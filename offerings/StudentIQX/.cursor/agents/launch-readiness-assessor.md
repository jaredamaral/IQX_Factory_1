## Domain Knowledge
Launch checklist: ICP approved (NOTE for StudentIQX: the ICP is an explicit
research objective — do not pass this criterion unless the ICP has actually been
validated, not merely hypothesized; the enrollment-band conflict must be
resolved); named buyer personas approved; top 3 use cases approved; Student 360
data model drafted; demo scenario built; sales narrative tested internally;
discovery framework complete; proof points sourced (Evidence Ledger has no open
`VERIFY` in canonical claims); objection handling complete; delivery model
drafted; pricing/package assumptions approved; value model complete; ≥3 target
accounts identified; known risks documented.

## Instructions
1. Read `AGENTS.md`, all Stage 2/3/4 outputs, then the shared files; load the skill.
2. Produce (1) a readiness assessment with pass/fail per criterion, gaps, and
   recommended pre-launch actions.
3. Run the **technical-honesty gate** — FAIL if any hold: prototype depends on
   React-only behavior not labeled aspirational; Sigma feasibility matrix
   missing/incomplete; Sigma pages don't map to MART_SIGMA/SEMANTIC/ACTIVATION;
   metrics inconsistent across use-case library, data model, and prototype spec;
   activation actions lack Snowflake logging/audit; unsupported Sigma features
   presented as canonical; synthetic data doesn't support the Agent 21 storyline.
4. Add the two addendum checks: a workbook-as-code file exists for every
   Sigma-native page; no unsupported element appears as generated workbook content.

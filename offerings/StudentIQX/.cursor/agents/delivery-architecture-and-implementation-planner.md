## Domain Knowledge
Higher-ed delivery realities (`HYPOTHESIS`): SIS integration is the long pole
(Banner/Colleague/PeopleSoft/Workday extract patterns differ); data ownership and
FERPA data-sharing agreements; IT/IR as gatekeepers; academic-calendar-driven
change windows; consensus/committee procurement; variable cloud/Snowflake
readiness (small institutions may lack it — a qualification check). Reference
architecture is Snowflake (data) + Sigma (experience) + Cortex (AI), with the
six governed layers. Coalesce is NOT assumed as the transform tool. Phase
delivery from a diagnostic/Student 360 foundation → prototype/pilot → activation.
Be explicit about client vs Verndale responsibilities and common blockers.

## Domain Knowledge
Generate realistic-but-synthetic higher-ed data across the six layers
(RAW_SYNTHETIC→CORE→MART_SIGMA→SEMANTIC→ACTIVATION→GOVERNANCE): students with
lifecycle stages, terms/enrollments, courses, engagement/LMS events, advising
alerts, financial-aid packages, gifts/alumni. Seed the specific "aha" moments the
Agent 21 storyline needs (e.g., an at-risk cohort that becomes visible only when
SIS+LMS+advising are unified). Include realistic edge cases (transfers, stop-outs,
readmits, duplicate identities). All data must be clearly labeled synthetic; PII
fields carry FERPA classification in GOVERNANCE; activation request/output/audit
tables are pre-populated per `activation-data-patterns.md`. Metrics come from
SEMANTIC (defined once). Cortex-derived scores land in governed tables. Data must
be reproducible (seeded generation logic).

# offerings/

Factory output. Each industry-specific IQX offering scaffold lives here as
`offerings/<Industry>IQX/`, generated by the `iqx-factory` skill in **Step 2**.

Empty until you invoke the factory (e.g. *"Run the factory for StudentIQX"*).
Each offering is self-contained: its own `AGENTS.md`, `manifest.yaml`, 27
`.cursor/agents/`, `agent-outputs/`, `prototype/`, `shared/`, and governance
ledgers. See `factory/templates/` for the layout the factory produces.

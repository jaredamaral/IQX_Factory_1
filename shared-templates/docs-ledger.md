# Documentation Ledger

## Purpose

This ledger tracks the official Sigma and Snowflake documentation used to populate the IQX shared knowledge pack. Agents should consume the distilled shared files, not raw documentation. Raw documentation is recorded here for traceability, review cadence, and future refresh.

## Review Status Values

- `seeded`: source identified and initial facts captured; deeper distillation still needed.
- `distilled`: source has been converted into one or more shared knowledge-pack rules.
- `needs-review`: source is likely relevant but has not been reviewed enough to guide agents.
- `blocked`: source requires private access, beta enrollment, or user-provided material.

## Distillation Rules

When a source is reviewed, update this ledger and then write the distilled rule into the appropriate shared file. Do not paste large sections of documentation into agent prompts.

Every distilled rule should include:

- What agents may assume.
- What agents must verify.
- Which IQX artifacts the rule affects.
- Whether the rule is platform fact, product doctrine, or implementation recommendation.
- Whether the rule is stable or should be rechecked frequently.
